# Карта невозможного

**AlphaGenome Atlas — популярным языком.** Дата-журналистский проект: четыре интерактивные истории о том, как нейросеть Google DeepMind предсказала молекулярный эффект **девяти миллиардов** возможных однобуквенных замен в ДНК человека — и какую часть этих предсказаний вообще можно проверить.

**Читать:** https://cosmiksoul.github.io/genomeatlas/

Проект сделан на данных [AlphaGenome Atlas](https://deepmind.google/blog/alphagenome-atlas-a-predictive-map-of-every-possible-dna-letter-change-in-the-human-genome/) (Google DeepMind, 2026) — прекомпьютед-предсказаний модели AlphaGenome для всех возможных SNV генома человека, — а также открытых баз ClinVar, gnomAD, Ensembl и MaveDB.

## Как это читать (если вы не биолог)

- **Опечатка** — замена одной «буквы» ДНК (A, C, G, T) на другую; по-научному — однонуклеотидный вариант, SNV. Возможных опечаток в геноме человека около девяти миллиардов: три миллиарда позиций × три «не те» буквы.
- **AVI** (AlphaGenome Variant Impact) — сводная оценка Атласа: насколько сильно замена меняет молекулярную работу участка ДНК. Собирается из предсказаний AlphaGenome (регуляция), AlphaMissense (поломка белка) и эволюционной консервативности.
- **Квантиль AVI** — главная шкала всех графиков проекта: доля замен генома, которые модель считает менее разрушительными, чем данную. 0,99 — «сильнее 99 %». Это **ранг внутри распределения модели**, а не калиброванная вероятность и не «вредность для здоровья».
- **Главное правило:** всё, что показывает модель, — предсказание, а не факт. Единственное экспериментальное измерение во всём проекте — saturation genome editing по BRCA1 (Findlay et al., Nature 2018) в четвёртой истории. Ограничения метода описаны в разделе «Что здесь не так, как в жизни» на каждой странице.

Каждая страница подсвечивает научные термины пунктиром — наведите курсор, чтобы увидеть определение. Источники и методология — в конце каждой истории.

## Что это и что это не

Это портфолио-проект дата-аналитика и научно-популярный лонгрид, **не научная публикация и не медицинская информация**. Предсказания AlphaGenome не валидированы для клинического применения — об этом прямо пишет сам DeepMind. Если у вас нашли вариант в BRCA1 или другом гене — интерпретировать его может только врач-генетик, а не нейросеть и тем более не этот сайт.

## Структура репозитория

```
site/                 готовые страницы — артефакт сборки, коммитятся; их публикует GitHub Pages
  index.html          обложка и оглавление
  genes.html          история 01
  tissues.html        история 02
  brca1.html          история 03
  finale.html         история 04
src/
  story*.py           ТЕКСТЫ историй, глоссарии, источники — единственное место, где живёт текст
  pull_atlas.py       Atlas API: окна ±5 кб для 10 генов → data/<GENE>_region.parquet, <GENE>_famous.json
  pull_tissues.py     Atlas API: тканевые скореры для 10 вариантов → data/tissues/<GENE>.parquet
  pull_brca1.py       Atlas API: весь BRCA1 чанками по 10 кб → data/brca1/*.parquet (34 МБ, в git не входит)
  fetch_brca1_sources.py  Ensembl / ClinVar / gnomAD / MaveDB (публичные API, без ключей)
  join_brca1_clinvar.py   ClinVar esummary → per-allele таблица → join с Atlas
  prep_site.py        story 01: site_data.json (+ Ensembl-структуры генов, перевод названий тканей)
  prep_tissues.py     story 02: tissues_data.json (+ systems.py — раскладка 711 образцов по 12 системам)
  prep_brca1.py       story 03: brca1_data.json
  prep_finale.py      story 04: finale_data.json (маппинг SGE c.→GRCh38, лестница проверки)
  build.py, realize.py    сборка истории 01 (template_genes.html → genes.html)
  build2/3/4.py       сборка историй 02–04
  inject_nav.py       обложка index.html + сквозное меню и favicon на всех страницах
  build_all.py        пересборка всего → ../site
  data/               обработанные данные (parquet/json); исключения — в .gitignore
.github/workflows/    CI: проверка воспроизводимости сборки + деплой на GitHub Pages
```

Все страницы — самодостаточные HTML без внешних зависимостей: данные вшиты в JSON, графика — рукописный SVG/canvas. Достаточно положить содержимое `site/` на любой статический хостинг.

## Воспроизведение

Два уровня, в зависимости от того, что вы хотите.

**Только пересборка страниц** из готовых данных (правка текстов, вёрстки) — нужен голый Python 3.10+, без зависимостей и без ключей:

```bash
cd src
python build_all.py       # → ../site/*.html
```

**Полный пайплайн** — забор данных заново (нужен ключ AlphaGenome API, некоммерческие условия):

```bash
cd src
pip install -r requirements.txt
cp .env.example .env                  # и вписать ALPHAGENOME_API_KEY

python pull_atlas.py 5000             # ~3 мин, 300 000 замен
python pull_tissues.py                # ~1 мин
python pull_brca1.py                  # ~5 мин, 390 000 замен; скрипт сам ждёт квоту
python fetch_brca1_sources.py         # Ensembl, ClinVar (11 655 записей), gnomAD, MaveDB
python join_brca1_clinvar.py

python prep_site.py && python prep_tissues.py && python prep_brca1.py && python prep_finale.py
python build_all.py
```

## Публикация

Сайт деплоится на GitHub Pages автоматически: workflow `.github/workflows/pages.yml` на каждый push в `main` сначала пересобирает страницы и проверяет, что `site/` совпадает с результатом сборки (защита от правок HTML руками мимо `story*.py`), затем публикует папку `site/`.

## Дизайн-система

Единая палитра: чернила `#17160f` (данные, патогенное), золото `#c4901e` (знаменитый вариант, усиление, неопределённость), бирюза `#2f6f7e` (ослабление, доброкачественное), бумага `#f5f2ec`. Серифный заголовочный шрифт (Iowan Old Style / Palatino / Georgia), моноширинный — для меток. У каждой истории свой визуальный язык: точечные матрицы и полосы (01), кольцо систем организма (02), штрих-код (03), вафля и лестница проверки (04).
